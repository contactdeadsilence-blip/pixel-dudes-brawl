# Pixel Dudes Brawl desktop launcher
Opens the live game; falls back to the bundled offline copy if offline. F11 toggles fullscreen.
Dev: `npm install && npm start`. Build locally: `npm run dist`.
Release: `git tag v1.0.1 && git push origin v1.0.1` — GitHub Actions builds Windows/Mac/Linux and publishes; installed apps auto-update.
